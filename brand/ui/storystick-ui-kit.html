Buttons

32 / 40 / 50 px

One cedar per screen

Drafting Blue is the workhorse primary. Cedar is reserved for the single most important action in view — usually the one that commits a measurement. Two cedar buttons on one screen means neither is primary.

Destructive is deep red

Plumb Red Deep #B93636, never the bright Plumb Red, because buttons carry text and must clear 4.5:1.

08 — Rules

Non-negotiables

Mono means exact

Any value the user could mis-read by a sixteenth is IBM Plex Mono. Prose is Inter. There is no third case.

Cedar is singular

One cedar element per view: the active tool, the selected object, or the primary action. Never all three.

Color is never alone

Every state that uses color also changes a shape, an icon, or a label. Sun glare and color vision deficiency both defeat color-only signals.

Touch targets are 40

Nothing interactive is under 40 px on touch. This app gets used with a pencil behind the ear and sawdust on the screen.

Both modes ship

Paper mode is not a dark-mode afterthought inverted. It is drawn, checked, and printed on its own terms.

No raw hex

Components reference tokens. When the palette shifts, one file changes.
